How to use comparison-matrix.csv (instructions kept out of the CSV so it loads cleanly in pandas, Excel and Sheets)

How to read this matrix (chapter 14.4): rows = papers, columns = the dimensions you compare on.
The column that is EMPTY across every prior row is your GAP. Here, no prior row measures
recall broken out BY ERROR TYPE against a human baseline -- that empty column becomes the
niche your Related Work section names and your paper occupies. Replace the placeholder rows
with your OWN verified papers; never invent a row to manufacture a gap.
