# Datasheet — <Dataset Name>

## Motivation
- For what purpose was the dataset created? <task, gap it fills>
- Who created it and who funded it? <people / institution / grant>

## Composition
- What does each instance represent? <a sentence, an image, a code-review comment...>
- How many instances are there, total? <N>, and per split? <train/val/test counts>
- What data does each instance consist of? <raw text? features? labels?>
- Is there a label / target? <what it is, how it was obtained>
- Are there known errors, noise, or redundancies? <describe>
- Does it contain confidential, personal, or sensitive data? <PII? consent? IRB/exempt status — note that exemption is determined by the IRB, not self-certified>

## Collection process
- How was the data acquired? <scraped / surveyed / logged / generated by an LLM>
- Over what timeframe was it collected? <dates>
- If generated by a model: which model, version, and date? <closed models drift — record it>
- Were the people whose data is included notified / did they consent? <yes/no/N-A>

## Preprocessing / cleaning / labeling
- What preprocessing was done? <which src/ script turns raw/ into processed/>
- Is the raw data preserved? <yes — raw/ is immutable>
- How were the train/val/test splits made, and is the split reproducible? <the rule + seed>
- Leakage check: was any transform (scaling, feature selection, tokenizer fitting)
  fit on data that includes the test set? <No — fit on train only>

## Uses
- What tasks is this dataset appropriate for? <list>
- What should it NOT be used for? <known limitations, populations, biases>
- For LLM evaluation: could this data have appeared in a model's pretraining
  (benchmark contamination)? <yes/no/unknown — and how you checked>

## Distribution & maintenance
- How is the dataset distributed, and under what license? <URL / DOI / license>
- Who maintains it, and how can it be contacted? <contact>
- Will it be updated? If so, how is the version pinned? <DVC / DOI per version>
